# Natural Earth's 110m coastline

A data.frame version of Natural Earth's 110m coastline polygon

## Usage

``` r
natural_earth_110m
```

## Format

- longitude:

  longitude values from -180 to 180

- latitude:

  latitude values from -85.61 to 83.65

- id:

  polygon ID

<https://www.naturalearthdata.com/downloads/110m-physical-vectors/110m-coastline/>
